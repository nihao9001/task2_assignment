# CodeTrack — Coding Practice Tracker

Task 2 individual ReactJS assignment based on Problem Statement 43: Coding Practice Tracker.

## Features
- Add, edit and delete practice problems
- Search by title, topic or platform
- Filter by status, difficulty and language
- Track solved, attempted and in-progress counts
- Calculate solved percentage
- Analytics view for difficulty and language breakdown
- Client-side validation for required fields and dates
- localStorage persistence
- CSV export
- Responsive layout for desktop and mobile

## Technologies
ReactJS 18, JavaScript ES6+, JSX, HTML5, CSS3, browser localStorage.

The project is kept as a single static index.html so it can run directly on GitHub Pages without a build server. React and ReactDOM are loaded from public UMD distributions and JSX is handled in-browser by Babel Standalone.

## Run
Open index.html in a browser with internet access.

For GitHub Pages, serve the repository root as the Pages source.

## Assignment mapping
Problem 43 requires recording coding problems, languages, difficulty levels and completion status. The application implements those fields plus CRUD, search/filtering, calculations, multiple views and form validation required by the common Task 2 requirements.
